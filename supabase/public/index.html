할 일

Supabase 설정이 필요합니다

  1. supabase.com 에서 무료 프로젝트를 만듭니다.
  2. 대시보드의 SQL Editor 에서 sql/ 폴더의 SQL 세 개를 순서대로 실행합니다.
    01_schema.sql → 02_rls.sql → 03_functions.sql
  3. Authentication > Sign In / Providers 에서 Email 을 켜고, 혼자 쓸 거라면 Confirm email 을 끕니다(메일 인증 없이 바로 로그인).
  4. Project Settings > API 에서 Project URL 과 anon(public) 키를 복사합니다.
  5. cp .env.example .env 후 두 값을 넣고 서버를 다시 켭니다.

service_role(secret) 키는 넣지 마세요. 그 키는 RLS 를 우회하므로 브라우저로 내려가는 순간 모든 사람의 데이터가 열립니다. 서버가 그 키를 감지하면 시작을 거부합니다.
